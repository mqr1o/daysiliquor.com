# Daysi Liquor

Website for a neighborhood liquor store on Mission Blvd in Hayward, CA.

**Live site:** https://daysiliquor.com

![Daysi Liquor homepage](screenshot.png)

## Features

- Bilingual: visitors choose English or Español on arrival
- Store hours, product selection and customer reviews sections
- Embedded Google Map and one-tap directions
- Responsive layout for phones and desktops

## Tech

A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step), hosted on Netlify with continuous deployment from this repository.
